One sentence, at most 200 characters, that explains the modern internet to
a time traveler who has just stepped out of the year 1800 — built only from
things a person of that year already knows: a road, letters, books,
newspapers, a door.

Entry for the [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the sentence to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`).
Standard library only, no network, deterministic.
